# Ограничения и безопасность

Скрипты работают в песочнице. Это защищает игру от зависаний, а компьютер от вредных скриптов.

## Что доступно из стандартной библиотеки

| Есть | Нет |
| --- | --- |
| базовые функции (`pairs`, `pcall`, `tostring`, …) | `io` (файлы) |
| `table`, `string`, `math`, `utf8`, `coroutine` | `os` |
| | `package`, `require` |
| | `debug` |
| | `dofile`, `loadfile` |

Для хранения данных используй [`storage`](../api/storage.md), для файлов-ресурсов используй [`render.setup_texture`](../api/render.md#textures), [`render.setup_font`](../api/render.md#fonts) и [`audio`](../api/audio.md).

## Лимит инструкций

Один вызов обработчика (и загрузка скрипта) может выполнить не больше **~20 миллионов инструкций Lua**. Если лимит превышен, например из-за бесконечного цикла, вызов прерывается с ошибкой `instruction budget exceeded (infinite loop?)`, а скрипт выключается.

Если тяжёлый кусок может упереться в лимит, оберни его в [`api.protect`](../api/globals.md#api): тогда скрипт не выключится, а функция вернёт ошибку `budget_exceeded`.

## Ошибки

* Ошибка при загрузке скрипта: скрипт не включается, текст ошибки виден в логе вкладки lua.
* Ошибка в обработчике события: скрипт **выключается**, текст ошибки с номером строки пишется в лог.

## Другие ограничения

| Что | Лимит |
| --- | --- |
| Окон `ui.create_window` на скрипт | 8 |
| Размер `storage` на скрипт | 64 KiB (в JSON) |
| Строк в логе вкладки | 200 последних |
| `console.exec` | до 1024 символов, выполняется в очереди, до 4 команд за кадр |
| `console.say` | до 200 символов, без `" ; \` и переводов строк |
