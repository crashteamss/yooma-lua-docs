# Установка скриптов

## Папка скриптов

Все скрипты лежат в:

```
%LOCALAPPDATA%\yooma\lua
```

Обычно это `C:\Users\<имя>\AppData\Local\yooma\lua`. Папка создаётся сама при первом запуске чита. Быстро открыть её можно кнопкой **open folder** во вкладке **lua** в меню.

Каждый файл `*.lua` в этой папке — отдельный скрипт.

## Структура папки

```
lua/
├── my_script.lua        ← скрипты
├── resources/           ← картинки для render.setup_texture (png, jpg, svg)
├── fonts/               ← шрифты для render.setup_font (ttf, otf)
├── muzon/  sounds/      ← звуки для audio.play (mp3, wav)
├── skeetles/            ← картинки (совместимость со skeet-скриптами)
└── storage/             ← сюда сохраняется storage.set (создаётся само)
```

Папки `resources`, `fonts`, `muzon`, `sounds` и `skeetles` создай сам, если скрипту нужны ресурсы. Файл можно положить и прямо рядом со скриптом: его тоже найдут по имени.

## Запуск

1. Положи `.lua` файл в папку.
2. В меню открой вкладку **lua** и нажми **refresh**, чтобы скрипт появился в списке.
3. Включи скрипт галочкой. Ошибки и вывод `print` видны в логе внизу вкладки.

**reload** перезагружает скрипт после правок, перезапускать игру не нужно.

{% hint style="info" %}
Если скрипт падает с ошибкой внутри обработчика события, он **автоматически выключается**, а текст ошибки с номером строки появляется в логе вкладки lua.
{% endhint %}
