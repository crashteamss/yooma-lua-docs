# Типы данных

## Цвет

Цвет — таблица из 4 чисел `{r, g, b, a}` от 0 до 255. Если какое-то значение не указано, оно равно 255.

```lua
local white  = {255, 255, 255, 255}
local red    = {255, 60, 60}          -- альфа = 255
local glass  = {0, 0, 0, 120}
```

## Вектор

Вектор — таблица с полями `x`, `y`, `z`. API принимает и массивную форму `{x, y, z}`, но **возвращает** всегда форму с полями.

```lua
local origin = {x = 100, y = 250, z = 64}
local same   = {100, 250, 64}

local me = entity.local_player()
print(me.origin.x, me.origin.y, me.origin.z)
```

Углы (`angles`) — тоже вектор: `x` = pitch, `y` = yaw, `z` = roll, в градусах.

## Id игроков

Игроки обозначаются целым **id**:

| id | Кто |
| --- | --- |
| `0` | ты (локальный игрок) |
| `1…64` | слот игрока в лобби |

`entity.local_player()` возвращает `id = 0`, `entity.players()` возвращает реальные слоты. Любую функцию, которая принимает id игрока, можно вызвать с `0`, чтобы получить себя.

## Таблица игрока

`entity.local_player()`, `entity.get(id)` и `entity.players()` возвращают таблицы вида:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | id игрока (см. выше) |
| `name` | string | ник |
| `health` | integer | здоровье |
| `armor` | integer | броня |
| `alive` | boolean | жив ли |
| `team` | integer | 2 — T, 3 — CT |
| `enemy` | boolean | противник ли (для себя всегда `false`) |
| `origin` | vector | позиция ног |
| `velocity` | vector | скорость |
| `flags` | integer | флаги (`flags & 1` — на земле) |
| `scoped` | boolean | в прицеле ли |

## Хэндлы

Текстуры, шрифты и материалы — это целые числа-**хэндлы**, которые возвращают функции `setup_*` и `create_*`. Хэндл живёт, пока включён скрипт.

## Клавиши

Там, где нужна клавиша, используется **виртуальный код Windows** (VK): `0x01` — ЛКМ, `0x02` — ПКМ, `0x05`/`0x06` — боковые кнопки мыши, `0x10` — Shift, `0x12` — Alt, `0x41…0x5A` — буквы A–Z, `0x70…` — F1….

## Хитгруппы

Значения `hitgroup` в событиях и в `combat.damage`:

| Значение | Часть тела |
| --- | --- |
| 0 | тело (общий) |
| 1 | голова |
| 2 | грудь |
| 3 | живот |
| 4 / 5 | левая / правая рука |
| 6 / 7 | левая / правая нога |
| 8 | шея |
